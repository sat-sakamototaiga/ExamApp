# CSVインポートで画像も取り込む機能 設計メモ

## 1. 目的
問題CSVインポート時に、問題画像および選択肢画像も同時に登録できるようにする。

- 対象機能: 問題インポート（教師以上）
- 非対象: ユーザーCSVインポート、既存の手動登録機能の仕様変更

## 2. 背景（現状）
現行システムでは、手動登録・編集では画像アップロード可能だが、CSVインポートでは画像列を扱っていない。

- DBには画像パスカラムが既に存在
- 表示側は storage 配下の相対パスを前提に描画
- CSVインポートはヘッダー厳密一致で検証

## 3. 採用方針
画像取り込み方式は以下3案を比較し、案Aを採用する。

- 案A（採用）: CSV + 画像ZIP同時アップロード
- 案B: CSVに既存サーバー内相対パスを記載
- 案C: CSVに外部URLを記載して取得

採用理由:
- 運用再現性が高い（持ち運びしやすい）
- SSRF等のネットワークリスクを回避しやすい
- 既存の storage 相対パス設計に適合

## 4. 仕様概要（案A）
### 4.1 入力
インポート画面で以下を指定する。

- インポート先試験
- CSVファイル（必須）
- 画像ZIP（任意）

CSV内に画像列がある場合のみZIPを参照し、画像列が空欄なら画像なしで登録する。

### 4.2 CSVヘッダー（新仕様）
既存列に加えて画像列を追加する。

- 問題文
- 問題画像
- 全体解説
- 選択肢1
- 選択肢1画像
- 正解1
- 解説1
- 選択肢2
- 選択肢2画像
- 正解2
- 解説2
- 選択肢3
- 選択肢3画像
- 正解3
- 解説3
- 選択肢4
- 選択肢4画像
- 正解4
- 解説4

補足:
- 画像列の値はZIP内のファイル名（例: q001.png, q001_opt1.jpg）
- サブディレクトリは不許可（ファイル名のみ許可）

### 4.3 ZIP仕様
- 形式: .zip
- 内容: CSVで参照する画像ファイル一式
- 許可拡張子: jpg, jpeg, png, webp, gif（要件に応じて縮小可）
- 1ファイル上限: 5MB
- 合計上限: 50MB（初期値。運用で調整）

### 4.4 保存仕様
- 画像は public ディスクに保存
- 保存先候補:
  - questions/imports/{import_id}/questions/
  - questions/imports/{import_id}/options/
- DBには相対パスを保存

## 5. バリデーション仕様
### 5.1 CSVレベル
- 文字コード正規化（既存仕様踏襲）
- ヘッダー一致検証
- 列数一致検証
- 問題文必須
- 正解選択肢が1つ以上必須

### 5.2 画像レベル
- 画像列に値がある場合、ZIP内に一致ファイルが必須
- ファイル名正規化（../ や / を禁止）
- MIMEと拡張子の両方を検証
- 上限サイズ超過は当該行エラー

## 6. エラーハンドリング方針
- 行単位で成功/失敗を判定し、継続可能なエラーはスキップ
- 最終的に「成功件数 + エラー詳細一覧」を返却
- 画像保存後にDB失敗した場合は補償削除を実施し、孤児ファイルを抑制

代表エラー例:
- 12行目: 問題画像「q012.png」がZIP内に存在しません
- 18行目: 選択肢2画像「../../x.png」は不正なファイル名です
- 25行目: 選択肢1画像「a.bmp」は許可されていない形式です

## 7. セキュリティ対策
- パストラバーサル対策（ファイル名のみ許可）
- MIME実体検証
- ZIP爆弾対策（展開サイズ・ファイル数・深さ制限）
- ログへの過剰な入力値出力を制限

## 8. 性能・運用
- 小〜中規模（例: 200問以内）は同期処理
- 大規模はジョブキュー化を検討
- タイムアウト/メモリ上限を環境ごとに調整

## 9. 既存ユーザー操作フロー（実装後）
### 9.1 教師の登録フロー（問題CSV + 画像）
1. 問題管理画面から「問題をインポート」を開く
2. インポート先試験を選択する
3. CSVテンプレートをダウンロードし、問題データを入力する
4. 画像を使う行だけ、画像列にZIP内ファイル名を記入する
5. 記入した画像ファイルをZIPにまとめる
6. 画面でCSVファイルを選択する
7. 画面で画像ZIPを選択する（画像なしなら省略可）
8. 「インポートを実行」を押す
9. 結果を確認する

結果表示:
- 全件成功: 成功件数メッセージ
- 一部失敗: 成功件数 + 行別エラー
- 全件失敗: 行別エラーのみ

### 9.2 教師の登録フロー（画像なしCSV）
1. 問題管理画面からインポート画面へ
2. 試験を選択
3. 画像列を空欄にしたCSVを選択
4. ZIP未指定で実行
5. 画像なし問題として登録

## 10. 影響範囲
- 画面: 問題インポート画面（ZIP選択欄追加、説明文更新）
- サーバー: 問題CSV取込処理（ヘッダー定義、ZIP解析、画像保存）
- テンプレート: CSVテンプレート列追加
- テスト: Featureテスト追加（正常系・部分失敗・不正ZIP・不正画像）

## 11. テスト観点（最低限）
- 正常系: CSV + ZIPで問題/選択肢画像が保存される
- 正常系: ZIPなし、画像列空欄で従来通り登録
- 異常系: CSVに指定した画像がZIP内にない
- 異常系: 拡張子偽装画像（MIME不一致）
- 異常系: 不正ファイル名（../ 含む）
- 異常系: ヘッダー不一致
- 回帰: 既存の手動登録・編集・表示が維持される

## 12. リスクと対応
- リスク: 処理時間増加
  - 対応: 件数上限、必要ならジョブ化
- リスク: 孤児ファイル
  - 対応: 失敗時の補償削除、定期クリーンアップ
- リスク: 運用ミス（ファイル名不一致）
  - 対応: 事前チェックと分かりやすい行別エラー

## 13. ロールアウト案
1. テンプレート更新（旧形式も短期互換）
2. ステージングで10件、50件、200件の取り込み検証
3. 本番展開（運用ガイド配布）
