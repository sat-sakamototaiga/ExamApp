# 脆弱性評価の明文化（IPAチェックリスト準拠）

- 対象: StudyTestApp
- 評価基準: 「安全なウェブサイトの作り方 改訂第7版」チェックリスト（提示CSV）
- 評価日: 2026-06-08
- 方針: 本書は「対応優先度の明確化」のみを目的とし、修正内容は含めない

## 最優先対応項目

### 1. 既知脆弱性を含む依存ライブラリの解消（No.10-(ii), No.8関連）
- 現状:
  - composer audit 実行結果で、11パッケージ・17件の脆弱性アドバイザリを検出
  - laravel/framework, symfony/mime, symfony/mailer, symfony/http-foundation など主要依存を含む
- リスク:
  - アプリコード側で対策していても、基盤ライブラリ起因の脆弱性影響を受ける
  - メールヘッダ注入、ルーティング/HTTP処理系の脆弱性に波及する可能性
- 優先理由:
  - 影響範囲が広く、横断的に複数機能へ影響し得るため

### 2. 例外メッセージ詳細の画面露出停止（No.1-(iii)）
- 現状:
  - 例外文字列をそのままユーザーに返却している箇所が存在
- リスク:
  - SQL/内部構造/スタックトレース断片などの情報漏えいにつながる
- 優先理由:
  - 攻撃者に探索情報を与える直接要因であり、是正コストに対して効果が高い

### 3. クリックジャッキング対策ヘッダの実装（No.9-(i)-a）
- 現状:
  - X-Frame-Options または CSP frame-ancestors の明示実装が未確認
- リスク:
  - 悪意ある外部サイト上の frame/iframe 埋め込みによるUI誘導攻撃
- 優先理由:
  - 防御ヘッダで広範な画面を一括保護でき、優先度が高い
